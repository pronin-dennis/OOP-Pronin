У процедурній версії дані про товари зберігалися в окремих масивах `names`, `prices` і `quantities`. Через це дані одного товару були пов'язані між собою лише за індексом. В ООП-версії назва та ціна об'єднані в класі `Product`, а робота з товарами виконується через клас `Cart`. Для додавання товару тепер достатньо використати метод `AddItem()`, а загальна сума обчислюється методом `GetTotal()`. Логіка знижки також знаходиться всередині `Cart`, тому не потрібно окремо передавати масиви у функцію знижки.

В ООП-версії стало простіше розширювати програму. Наприклад, для видалення товару можна додати метод `RemoveItem()` без зміни структури всіх даних. Також об'єкт `Cart` можна повторно використати в іншій частині програми, передавши його як готовий об'єкт. Тому в цьому прикладі ООП-версія має більш зручну структуру для подальшого розширення програми.
